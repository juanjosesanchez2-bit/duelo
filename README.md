
# 💜 Desafío del Duelo

Juego educativo interactivo sobre los procesos de duelo en las diferentes etapas de la vida.

## Características
- 14 preguntas de selección múltiple.
- Cuatro opciones por pregunta.
- 10 puntos por respuesta correcta.
- Preguntas aleatorias.
- Retroalimentación inmediata.
- Resultados y porcentaje final.
- Se gana al superar el 65% de respuestas correctas.

## Tecnologías
- Python
- Streamlit

## Cómo ejecutar
```bash
pip install -r requirements.txt
streamlit run app_desafio_duelo.py
```
